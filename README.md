# Cognito

Cognito is an advanced, high-performance mobile application focused on cognitive enhancement and AI-driven academic assessment.

## Features
- **Cognitive Core Games**: Mental Math, Memory Flip, Spatial Vision, Logic Test
- **Academic AI Engine**: Generates 100% syllabus-aligned questions (KSSM) using Llama 3.3 70B via Groq API.
- **Dynamic Theming**: Advanced memory-mutation engine for instant Light/Dark mode switching.
- **Live Leaderboard & Stats**: Synced with Firebase Firestore.
